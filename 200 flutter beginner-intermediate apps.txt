Buatkan panduan  dan file lengkap proyek Flutter untuk web, android dan windows di bawah ini, 
Judul : 



UI/UX standart profesional, designer grade.
Terapkan modular programming dengan panjang lines setiap file seminimal mungkin, dan setiap file di tulis di masing-masing artifact agar mudah di copy. pastikan tidak ada missing import di setiap file.
jangan gunakan syntax code yang sudah deprecated di 2026, versi library yang paling up to date
mulai dari inisialisasi proyek
sertakan code bash touch mkdir untuk membuat struktur file lengkap semua file termasuk di root.
tidak usah pakai demo tampilan, tidak usah pakai README.MD,
nama proyek pakai snake case


code dalam artifact lengkap dengan penjelasan singkat setiap code dalam bentuk komentar, jelaskan setiap baris kecuali code yang pengulangan sudah dibahas sebelumnya, komentar selalu di atas code yang dijelaskan, jangan di bawahnya

buat code dalam beberapa 10-15 part dengan tahapan seperti professional atau real developer akan mengembangkan app ini, jelaskan alurnya,  apa dulu yang dibuat kemudian selanjutnya bagian mana hingga akhir finalisasinya
Intinya proyek ini tujuan utamanya buat belajar, jadi optimalkan untuk pemahaman maksimal belajar flutter
setiap tahap harus sudah bisa langsung dilihat hasilnya.

mulai dari tahap 1 dulu, sertakan juga 1 dokumen khusus di artifact, penjelasan code level pemula, jelaskan logika algoritmanya dan pengetahuan penting lainnya
